E-Commerce Website (MERN Stack)

This is a full-featured E-Commerce platform built using the MERN stack (MongoDB, Express.js, React.js, Node.js), delivering a seamless online shopping experience.

This project was built as a personal project to demonstrate full-stack capabilities, from frontend state management to backend API design and payment integration.

🚀 Key Features

1. User Features

Product Browsing: Clean, responsive UI for browsing products.

User Profile Management: Secure user registration, login, and profile updates.

Cart Functionality: Add, remove, and manage items in the shopping cart.

Secure Payments: Integrated Braintree (PayPal) payment gateway for secure transactions.

2. Admin Dashboard

CRUD Operations: Full CRUD (Create, Read, Update, Delete) functionality for product categories and individual products.

Order Status Tracking: Admins can view and update the status of customer orders (e.g., "Processing", "Shipped").

Inventory Control: Manage product stock and availability.

3. Technical Highlights

Advanced Search & Filtering: Implemented optimized product search and filtering logic for a better user experience.

RESTful API: Designed and developed a complete set of REST APIs to handle all backend operations and real-time transactions.

Responsive Design: The frontend is fully responsive and dynamic.

🛠️ Tech Stack

Frontend: React.js

Backend: Node.js, Express.js

Database: MongoDB

Payments: Braintree (PayPal)
